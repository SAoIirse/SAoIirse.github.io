栈和栈帧

发表于2026-09-27|更新于2026-10-01|《逆向工程核心原理》
|浏览量:

栈应于存储局部变量，传递函数参数，保存函数返回地址。调试程序应该不断观察栈内存。
在逆向的时候我们经常说到的bp，sp都和栈有关，汇编语言表达栈段为寄存器SS，SP在汇编中则表示栈顶在段内的偏移。

栈的作用

1.暂时保护函数内的局部变量
2.调用函数时传递参数
3.保存函数返回后的地址

ESP为栈顶指针，初始在栈底(高地址)，PUSH使ESP自减移到栈顶方向。

栈指针变化规律：

栈指针随着压栈出栈的数据移动，入栈时栈指针地址减少，出栈时栈指针地址增加。栈顶地址小于栈底地址。
判断方法

  1. 看助记符，判断属于哪类：
    ○ push / call → 入栈
    ○ pop / ret → 出栈
    ○ sub esp, N → 分配（栈顶下降）
    ○ add esp, N / mov esp, ebp / leave → 回收（栈顶上升）
    ○ 其余 → 一般不动 ESP
  2. 改 ESP：
    ○ x86：每次 ±4
    ○ x64：每次 ±8
  3. 写/读栈内存（只有 push/pop/call/ret 才真正读写栈内容；sub esp 只是移动指针，不清内存）。
  4. 注意隐式入栈：call 会自动压入返回地址，ret 会自动弹出返回地址，这两条最容易被漏掉。

实验1–栈变化实例演示：

想要知道栈真正的入栈出栈情况，需要紧盯esp（rsp）的变化，结合hellloworld程序进行栈模拟。记住此时esp地址是0x1AFF74。


1.push ebp 压入栈帧 ESP-8=0x1AFF6C

2.push ebx 入栈 ESP-8=0x1AFF64

3.push edi 入栈 ESP-8=0x1AFF5C

4.push esi 入栈 ESP-8=0x1AFF54

5.push eax 入栈 ESP-8=0x1AFF4C

6.push eax 入栈 ESP-8=0x1AFF44

7.pop esi 出栈 ESP+8=0x1AFF5C
这里特殊的是在esi出栈前eax就已经出栈过了，因为eax是易失性寄存器API 读取参数后API 内部自动把参数出栈（清理掉），或者由后续的 add esp, X 清理。

8.pop edi 出栈 ESP+8=0x1AFF64

9.pop ebx 出栈 ESP+8=0x1AFF6C

栈帧：

利用EBP（这是栈帧指针）寄存器访问栈内局部变量，参数，函数返回地址等手段。调用某函数时，要先把用作基准点（函数起始地址）的ESP值保存到EBP中，并维持在函数内部。

相当于，对起始地址的状态进行一个存档。使程序能够安全访问到相关函数的局部变量，参数，返回地址。
