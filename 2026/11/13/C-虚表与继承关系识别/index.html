C++虚表与继承关系识别

发表于2026-11-13|更新于2026-11-14|windows逆向
|浏览量:

C++基础知识前言：

内存分配

类

认为和 python 相似但出现一些专业术语：
构造函数：负责初始化
析构函数：负责清理。
构造函数的时候不能有虚函数，但析构函数的时候可以。

析构函数：为了释放对象占用的资源

  1. 函数名：~+类名；
  2. 无参数，无返回类型
  3. 一个类只能有一个析构函数
  4. 对象销毁自动调用
    构造顺序：先构造父类再按照声明顺序构造成员对象和初始化列表中指定成员
    析构顺序：先调用自身的析构函数，然后调用成员对象的析构函数，最后调用

多态

C++多态性，作为面向对象编程的重要特性，允许使用同一接口处理不同类型对象。

多态是不同继承关系的类对象，同意调用函数，产生不同行为。
构成条件：

  1. 必须通过基类的指针或者引用调用虚函数
  2. 被调用的函数必须全是虚函数，且派生类必须对基类的函数进行重写。

虚函数

虚函数是 C++ 实现运行时多态的核心机制。表现为在基类中用 virtual 关键字声明的函数，允许派生类重写。
虚函数执行的原理：
这个虚函数真正的调用关系程序执行路径，是由运行时对象真实类型决定的。含有虚函数的类中编译器会构建一张虚函数表，对象里存有一个指向虚函数表的指针。

  1. 程序编译期，编译器按照指针的静态类型生成查找 vtable[ 虚函数表 ] 的指令，但不决定最终调用具体函数。
  2. 运行期，程序会顺着指针找到对象的 vptr[ 虚指针 ]，查到对象真实类型对应的 vtable，取出虚函数表中这个函数的地址并调用。

    基类和派生类：面向对象变成中继承关系的两个角色，关系相当于父类和子类
    基类：被继承的类，定义通用属性和行为
    派生类：继承自基类的类，在基类的基础上修改或者增加。

虚析构函数（virtual destructor）

虚析构函数帮助代码实现基类指针删除派生类对象。特征仍为家里 virtual 关键字的析构函数，本质上仍是析构函数，目的是让 delete 基类指针时能够正确调用到派生类的析构。

不同的是，虚析构函数是删除基类指针去删除其所指对象时，由于析构是虚的，所以程序会按照对象真实类型先调用派生类析构，再自动调用基类析构，完整释放对象资源；如果析构不是虚的，那么只会调用基类析构，派生类部分清理不到，容易造成资源泄露。

虚函数调用链路：

C++支持单一继承【direct base class只有一个】，多重继承【direct base classes不只一个】和虚拟继承【多重继承下，让共同的祖父级能够被共享，不至于良妃记忆体空间】三种关系。
